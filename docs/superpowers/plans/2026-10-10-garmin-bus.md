# Garmin Bus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Connect IQ watch app with a glance. It shows the next real-time departures for saved favorites (one exact platform + one line), uses Entur (Norway), and keeps a provider layer that other countries can be added to.

**Architecture:** Monkey C watch app with no server. UI code talks only to `DepartureService`, `FavoritesStore` and the common models (plain Dictionaries with fixed keys, built by `Model`). A `Provider` (currently only `EnturProvider`) builds the HTTP request and parses the response into those models. Parsing is unit-tested against captured Entur JSON that is converted into Monkey C fixture functions.

**Tech Stack:** Connect IQ SDK (Monkey C), `monkeyc` / `monkeydo` CLI, Connect IQ simulator, Entur Journey Planner v3 GraphQL, Python 3 (dev tooling only), Make.

**Spec:** `docs/superpowers/specs/2026-10-10-garmin-bus-design.md`

## Global Constraints

- Targets: **Venu 4** (primary) and **Vivoactive 6**. Device IDs are confirmed against the installed SDK in Task 1 and must match in `manifest.xml` and `Makefile`.
- All user-facing text comes from `resources/strings/strings.xml` (Norwegian bokmål is the default set). No literal UI text in `.mc` files, except the Task 1 hello screen, which is deleted in Task 6.
- Entur endpoint: `POST https://api.entur.io/journey-planner/v3/graphql`, header `ET-Client-Name: boolsen-nesteavgang`, no API key.
- A favorite is keyed by **provider + quayId + lineId**. Never by stop name or destination text.
- Nearby-stop radius: 500 m, max 10 stops.
- App view: next 3 departures, refreshed on show and every 30 s while visible. Glance: next departure of favorite #1.
- Every class/module used by the glance is annotated `(:glance)`. Every string used by glance code has `scope="glance"`.
- Line labels use ASCII `>` (e.g. `10 > Mulen`). The spec shows `→`, but that glyph is not guaranteed in Garmin fonts.
- Developer key lives outside the repo (`~/.garmin/developer_key.der`). Never commit `*.der` / `*.pem`.
- Every commit message ends with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (after a blank line).

## Deviations from the spec (intentional)

- Milestone 3 (provider layer) is built **before** the hardcoded on-watch pipeline (Tasks 2–5 before Task 6). The parsing code is tested first, so the hardcoded milestone (Task 6) already uses the final architecture and no throwaway code is written.
- If you have no favorites, the app view opens the Add flow automatically **once** per app launch. After that, the empty screen shows "Legg til favoritt", and tapping opens the menu.

```python
"""Generate resources/drawables/launcher_icon.png (60x60 RGBA) using only the stdlib."""
import struct
import sys
import zlib

W = H = 60


def px(x, y):
    cx = cy = 29.5
    if (x - cx) ** 2 + (y - cy) ** 2 > 29.5 ** 2:
        return (0, 0, 0, 0)
    if 16 <= x <= 43 and 14 <= y <= 40:          # bus body
        if 19 <= x <= 40 and 17 <= y <= 27:      # windscreen
            return (0, 70, 140, 255)
        return (255, 255, 255, 255)
    if (20 <= x <= 25 or 34 <= x <= 39) and 41 <= y <= 45:  # wheels
        return (255, 255, 255, 255)
    return (0, 70, 140, 255)


def chunk(tag, data):
    return struct.pack(">I", len(data)) + tag + data + struct.pack(">I", zlib.crc32(tag + data) & 0xFFFFFFFF)


raw = b"".join(b"\x00" + bytes(c for x in range(W) for c in px(x, y)) for y in range(H))
png = (b"\x89PNG\r\n\x1a\n"
       + chunk(b"IHDR", struct.pack(">IIBBBBB", W, H, 8, 6, 0, 0, 0))
       + chunk(b"IDAT", zlib.compress(raw))
       + chunk(b"IEND", b""))
with open(sys.argv[1], "wb") as f:
    f.write(png)
```

```monkeyc
import Toybox.Lang;
import Toybox.Time;
import Toybox.Time.Gregorian;

(:glance)
module TimeUtil {
    // "2026-10-10T10:23:00+02:00", "...Z" or with fractional seconds -> UTC epoch seconds.
    function parseIso8601(s as String) as Number or Null {
        var len = s.length();
        if (len < 19) {
            return null;
        }
        var year = s.substring(0, 4).toNumber();
        var month = s.substring(5, 7).toNumber();
        var day = s.substring(8, 10).toNumber();
        var hour = s.substring(11, 13).toNumber();
        var minute = s.substring(14, 16).toNumber();
        var second = s.substring(17, 19).toNumber();
        if (year == null || month == null || day == null || hour == null || minute == null || second == null) {
            return null;
        }

        // Skip fractional seconds, find zone designator.
        var i = 19;
        while (i < len) {
            var c = s.substring(i, i + 1);
            if (c.equals("Z") || c.equals("+") || c.equals("-")) {
                break;
            }
            i++;
        }
        var offset = 0;
        if (i < len && !s.substring(i, i + 1).equals("Z")) {
            if (len < i + 6) {
                return null;
            }
            var oh = s.substring(i + 1, i + 3).toNumber();
            var om = s.substring(i + 4, i + 6).toNumber();
            if (oh == null || om == null) {
                return null;
            }
            offset = oh * 3600 + om * 60;
            if (s.substring(i, i + 1).equals("-")) {
                offset = -offset;
            }
        }

        // Gregorian.moment interprets the fields as UTC.
        var m = Gregorian.moment({
            :year => year, :month => month, :day => day,
            :hour => hour, :minute => minute, :second => second
        });
        return m.value() - offset;
    }

    // Whole minutes until epoch, or -1 if it has already passed.
    function minutesUntil(epoch as Number, now as Number) as Number {
        var diff = epoch - now;
        if (diff < 0) {
            return -1;
        }
        return diff / 60;
    }
}
```

```monkeyc
import Toybox.Lang;
import Toybox.Time;
import Toybox.Time.Gregorian;
import Toybox.WatchUi;

(:glance)
module Fmt {
    function str(id as Symbol) as String {
        return WatchUi.loadResource(id) as String;
    }

    function minutes(min as Number, realtime as Boolean) as String {
        var s = (min == 0) ? str(Rez.Strings.Now) : Lang.format(str(Rez.Strings.MinutesFmt), [min]);
        return realtime ? s : Lang.format(str(Rez.Strings.ApproxFmt), [s]);
    }

    function clock(epoch as Number) as String {
        var info = Gregorian.info(new Time.Moment(epoch), Time.FORMAT_SHORT);
        return Lang.format("$1$:$2$", [(info.hour as Number).format("%02d"), (info.min as Number).format("%02d")]);
    }
}
```

```python
"""Convert JSON fixture files into a Monkey C module of fixture functions.

Usage: python3 -I tools/json2mc.py test/fixtures/json/*.json > test/Fixtures.mc
Each file <stem>.json becomes `function <stem>() as Dictionary`.
"""
import json
import pathlib
import sys


def lit(v, indent):
    pad = "    " * indent
    if v is None:
        return "null"
    if v is True:
        return "true"
    if v is False:
        return "false"
    if isinstance(v, int):
        return f"{v}l" if abs(v) > 2**31 - 1 else str(v)
    if isinstance(v, float):
        return repr(v)
    if isinstance(v, str):
        return '"' + v.replace("\\", "\\\\").replace('"', '\\"').replace("\n", "\\n") + '"'
    if isinstance(v, list):
        if not v:
            return "[]"
        inner = (",\n").join(pad + "    " + lit(x, indent + 1) for x in v)
        return "[\n" + inner + "\n" + pad + "]"
    if isinstance(v, dict):
        if not v:
            return "{}"
        inner = (",\n").join(pad + "    " + lit(k, 0) + " => " + lit(x, indent + 1) for k, x in v.items())
        return "{\n" + inner + "\n" + pad + "}"
    raise TypeError(type(v))


out = ["// GENERATED by tools/json2mc.py - do not edit", "import Toybox.Lang;", "", "module Fixtures {"]
for path in sorted(sys.argv[1:]):
    p = pathlib.Path(path)
    data = json.loads(p.read_text(encoding="utf-8"))
    out.append(f"    function {p.stem}() as Dictionary {{")
    out.append("        return " + lit(data, 2) + ";")
    out.append("    }")
    out.append("")
out.append("}")
sys.stdout.write("\n".join(out) + "\n")
```

```monkeyc
import Toybox.Communications;
import Toybox.Lang;

(:glance)
class EnturProvider extends Provider {
    const URL = "https://api.entur.io/journey-planner/v3/graphql";
    const CLIENT_NAME = "boolsen-nesteavgang";

    const DEPARTURES_QUERY = "query($q:String!,$l:[ID!],$n:Int!){quay(id:$q){estimatedCalls(numberOfDepartures:$n,whiteListed:{lines:$l}){expectedDepartureTime realtime destinationDisplay{frontText} serviceJourney{line{publicCode}}}}}";

    function initialize() {
        Provider.initialize();
    }

    function id() as String {
        return "entur";
    }

    function buildDeparturesRequest(fav as Dictionary, count as Number) as Dictionary or Null {
        return request(DEPARTURES_QUERY, {"q" => fav["quayId"], "l" => [fav["lineId"]], "n" => count});
    }

    function parseDepartures(data) as Array or Null {
        var calls = dig(data, ["data", "quay", "estimatedCalls"]);
        if (!(calls instanceof Array)) {
            return null;
        }
        var result = [];
        for (var i = 0; i < calls.size(); i++) {
            var c = calls[i];
            var time = dig(c, ["expectedDepartureTime"]);
            var line = dig(c, ["serviceJourney", "line", "publicCode"]);
            var dest = dig(c, ["destinationDisplay", "frontText"]);
            if (time == null || line == null || dest == null) {
                continue;
            }
            var epoch = TimeUtil.parseIso8601(time as String);
            if (epoch == null) {
                continue;
            }
            result.add(Model.departure(line as String, dest as String, epoch, c["realtime"] == true));
        }
        return result;
    }

    hidden function request(query as String, variables as Dictionary) as Dictionary {
        return {
            "url" => URL,
            "params" => {"query" => query, "variables" => variables},
            "options" => {
                :method => Communications.HTTP_REQUEST_METHOD_POST,
                :headers => {
                    "Content-Type" => Communications.REQUEST_CONTENT_TYPE_JSON,
                    "ET-Client-Name" => CLIENT_NAME
                },
                :responseType => Communications.HTTP_RESPONSE_CONTENT_TYPE_JSON
            }
        };
    }
}
```

```monkeyc
import Toybox.Communications;
import Toybox.Lang;

(:glance)
module ServiceError {
    enum Kind {
        NO_PHONE = 1,
        HTTP_ERROR = 2,
        PARSE_ERROR = 3,
        NO_DEPARTURES = 4
    }

    function fromResponseCode(code as Number) as Number or Null {
        if (code == 200) {
            return null;
        }
        if (code == Communications.BLE_CONNECTION_UNAVAILABLE || code == Communications.BLE_HOST_TIMEOUT) {
            return NO_PHONE;
        }
        return HTTP_ERROR;
    }

    function message(err as Number, code as Number) as String {
        if (err == NO_PHONE) {
            return Fmt.str(Rez.Strings.NoPhone);
        }
        if (err == PARSE_ERROR) {
            return Fmt.str(Rez.Strings.ParseError);
        }
        if (err == NO_DEPARTURES) {
            return Fmt.str(Rez.Strings.NoDepartures);
        }
        return Lang.format(Fmt.str(Rez.Strings.ErrorFmt), [code]);
    }
}
```

```monkeyc
import Toybox.Lang;
import Toybox.Time;

// One departures fetch for one favorite. Create a new instance per fetch so that
// overlapping requests (e.g. user swiped to another favorite) never share state.
(:glance)
class DepartureService {
    hidden var _fav as Dictionary;
    hidden var _callback as Method;
    hidden var _provider;

    // callback: (fav as Dictionary, deps as Array or Null, error as Number or Null, code as Number) as Void
    function initialize(fav as Dictionary, callback as Method) {
        _fav = fav;
        _callback = callback;
        _provider = ProviderRegistry.get(fav["provider"] as String);
    }

    function send(count as Number) as Void {
        Net.send(_provider.buildDeparturesRequest(_fav, count), method(:onResponse));
    }

    function onResponse(code as Number, data) as Void {
        var error = ServiceError.fromResponseCode(code);
        var deps = null;
        if (error == null) {
            deps = _provider.parseDepartures(data);
            if (deps == null) {
                error = ServiceError.PARSE_ERROR;
            } else if (deps.size() == 0) {
                error = ServiceError.NO_DEPARTURES;
            } else {
                // Storage may be read-only in glance context on some devices; cache is best-effort.
                try {
                    DepartureCache.put(_fav, deps, Time.now().value());
                } catch (e) {
                }
            }
        }
        _callback.invoke(_fav, deps, error, code);
    }
}
```

```monkeyc
import Toybox.Application;
import Toybox.Lang;

// Ordered list of Favorite dictionaries. Index 0 is shown in the glance.
(:glance)
module FavoritesStore {
    const KEY = "favorites";

    function all() as Array {
        var v = Application.Storage.getValue(KEY);
        return (v == null) ? [] : v as Array;
    }

    function count() as Number {
        return all().size();
    }

    function get(i as Number) as Dictionary or Null {
        var a = all();
        return (i >= 0 && i < a.size()) ? a[i] as Dictionary : null;
    }

    function add(fav as Dictionary) as Number {
        var a = all();
        for (var i = 0; i < a.size(); i++) {
            if (Model.sameFavorite(a[i] as Dictionary, fav)) {
                return i;
            }
        }
        a.add(fav);
        Application.Storage.setValue(KEY, a);
        return a.size() - 1;
    }

    function remove(i as Number) as Void {
        var a = all();
        if (i < 0 || i >= a.size()) {
            return;
        }
        Application.Storage.setValue(KEY, without(a, i));
    }

    function moveToTop(i as Number) as Void {
        var a = all();
        if (i <= 0 || i >= a.size()) {
            return;
        }
        Application.Storage.setValue(KEY, [a[i]].addAll(without(a, i)));
    }

    function clear() as Void {
        Application.Storage.deleteValue(KEY);
    }

    function without(a as Array, i as Number) as Array {
        return a.slice(0, i).addAll(a.slice(i + 1, null));
    }
}
```

```monkeyc
class DeparturesView extends WatchUi.View {
    const SHOWN = 3;
    const FETCH = 4;           // one extra so a departure passing between refreshes doesn't leave a gap
    const REFRESH_MS = 30000;

    var index as Number = 0;
    hidden var _deps = null;
    hidden var _error = null;
    hidden var _code = 0;
    hidden var _updated = null;
    hidden var _loading = false;
    hidden var _refreshTimer;

    function initialize() {
        View.initialize();
        _refreshTimer = new Timer.Timer();
    }

    function onShow() as Void {
        refresh();
        _refreshTimer.start(method(:refresh), REFRESH_MS, true);
    }

    function onHide() as Void {
        _refreshTimer.stop();
    }

    function showIndex(i as Number) as Void {
        var n = FavoritesStore.count();
        index = (n == 0) ? 0 : ((i % n) + n) % n;
        _deps = null;
        _error = null;
        _updated = null;
        refresh();
    }

    function refresh() as Void {
        var fav = FavoritesStore.get(index);
        if (fav == null) {
            WatchUi.requestUpdate();
            return;
        }
        if (_deps == null) {
            var cached = DepartureCache.get(fav);
            if (cached != null) {
                _deps = cached["d"];
                _updated = cached["t"];
            }
        }
        _loading = true;
        new DepartureService(fav, method(:onResult)).send(FETCH);
        WatchUi.requestUpdate();
    }

    function onResult(fav as Dictionary, deps as Array or Null, error as Number or Null, code as Number) as Void {
        var current = FavoritesStore.get(index);
        if (current == null || !Model.sameFavorite(current, fav)) {
            return; // stale response for a favorite we've swiped away from
        }
        _loading = false;
        _error = error;
        _code = code;
        if (deps != null) {
            _deps = deps;
            _updated = Time.now().value();
        }
        WatchUi.requestUpdate();
    }

    function onUpdate(dc as Graphics.Dc) as Void {
        var center = Graphics.TEXT_JUSTIFY_CENTER | Graphics.TEXT_JUSTIFY_VCENTER;
        var w = dc.getWidth();
        var h = dc.getHeight();
        var cx = w / 2;
        dc.setColor(Graphics.COLOR_WHITE, Graphics.COLOR_BLACK);
        dc.clear();

        var fav = FavoritesStore.get(index);
        if (fav == null) {
            dc.drawText(cx, h / 2, Graphics.FONT_SMALL, Fmt.str(Rez.Strings.AddFavorite), center);
            return;
        }

        dc.drawText(cx, h * 0.17, Graphics.FONT_SMALL, fav["label"] as String, center);
        dc.setColor(Graphics.COLOR_LT_GRAY, Graphics.COLOR_TRANSPARENT);
        dc.drawText(cx, h * 0.27, Graphics.FONT_XTINY, fav["stopName"] as String, center);

        var shown = (_deps == null) ? [] : Model.upcoming(_deps, now, SHOWN);
        dc.setColor(Graphics.COLOR_WHITE, Graphics.COLOR_TRANSPARENT);
        for (var i = 0; i < shown.size(); i++) {
            var d = shown[i];
            var text = Fmt.minutes(TimeUtil.minutesUntil(d["epoch"] as Number, now), d["rt"] as Boolean)
                + "  " + d["dest"];
            dc.drawText(cx, h * (0.42 + 0.12 * i), Graphics.FONT_SMALL, text, center);
        }

        var status = null;
        if (_error != null) {
            status = ServiceError.message(_error, _code);
```

```monkeyc
    function buildNearbyStopsRequest(lat as Double, lon as Double) as Dictionary or Null {
        return request(NEARBY_QUERY, {"lat" => lat, "lon" => lon});
    }

    function parseNearbyStops(data) as Array or Null {
        var edges = dig(data, ["data", "nearest", "edges"]);
        if (!(edges instanceof Array)) {
            return null;
        }
        var result = [];
        for (var i = 0; i < edges.size(); i++) {
            var id = dig(edges[i], ["node", "place", "id"]);
            var name = dig(edges[i], ["node", "place", "name"]);
            var dist = dig(edges[i], ["node", "distance"]);
            if (id == null || name == null || dist == null) {
                continue;
            }
            result.add(Model.nearbyStop(id as String, name as String, (dist as Float).toNumber()));
        }
        return result;
    }

    function buildLineOptionsRequest(stopId as String) as Dictionary or Null {
        return request(LINE_OPTIONS_QUERY, {"id" => stopId});
    }

    function parseLineOptions(data) as Array or Null {
        var quays = dig(data, ["data", "stopPlace", "quays"]);
        if (!(quays instanceof Array)) {
            return null;
        }
        var result = [];
        for (var q = 0; q < quays.size(); q++) {
            var quayId = dig(quays[q], ["id"]);
            var lines = dig(quays[q], ["lines"]);
            var calls = dig(quays[q], ["estimatedCalls"]);
            if (quayId == null || !(lines instanceof Array)) {
                continue;
            }
            for (var l = 0; l < lines.size(); l++) {
                var lineId = dig(lines[l], ["id"]);
                var code = dig(lines[l], ["publicCode"]);
                if (lineId == null || code == null) {
                    continue;
                }
                var dests = [];
                if (calls instanceof Array) {
                    for (var c = 0; c < calls.size() && dests.size() < MAX_DESTS; c++) {
                        var callLine = dig(calls[c], ["serviceJourney", "line", "id"]);
                        var dest = dig(calls[c], ["destinationDisplay", "frontText"]);
                        if (callLine != null && dest != null && (callLine as String).equals(lineId) && !contains(dests, dest as String)) {
                            dests.add(dest);
                        }
                    }
                }
                var label = code as String;
                for (var d = 0; d < dests.size(); d++) {
                    label += (d == 0 ? " > " : " / ") + dests[d];
                }
                result.add(Model.lineOption(quayId as String, lineId as String, code as String, label));
            }
        }
        return result;
    }

    hidden function contains(arr as Array, s as String) as Boolean {
        for (var i = 0; i < arr.size(); i++) {
            if (s.equals(arr[i])) {
                return true;
            }
        }
        return false;
    }
```

```monkeyc
    hidden var _text as String;
    hidden var _retry = null;

    function initialize(text as String) {
        View.initialize();
        _text = text;
    }

    function setText(text as String) as Void {
        _text = text;
        _retry = null;
        WatchUi.requestUpdate();
    }

    function setError(text as String, retry as Method) as Void {
        _text = text + "\n" + Fmt.str(Rez.Strings.TapToRetry);
        _retry = retry;
        WatchUi.requestUpdate();
    }

    function retry() as Boolean {
        if (_retry == null) {
            return false;
        }
        var r = _retry;
        _retry = null;
        r.invoke();
        return true;
    }

    function onUpdate(dc as Graphics.Dc) as Void {
        dc.setColor(Graphics.COLOR_WHITE, Graphics.COLOR_BLACK);
        dc.clear();
        dc.drawText(dc.getWidth() / 2, dc.getHeight() / 2, Graphics.FONT_SMALL, _text,
            Graphics.TEXT_JUSTIFY_CENTER | Graphics.TEXT_JUSTIFY_VCENTER);
    }
}

class StatusDelegate extends WatchUi.BehaviorDelegate {
    hidden var _view as StatusView;

    function initialize(view as StatusView) {
        BehaviorDelegate.initialize();
        _view = view;
    }

    function onSelect() as Boolean {
        return _view.retry();
    }
}
```

```monkeyc
import Toybox.Lang;
import Toybox.Position;
import Toybox.Timer;
import Toybox.WatchUi;

// GPS -> nearby stops -> (quay, line) options -> save favorite.
// Occupies one view-stack slot above DeparturesView; steps replace each other with switchToView.
// Back from any step returns to DeparturesView.
class AddFavoriteFlow {
    const GPS_TIMEOUT_MS = 30000;

    hidden var _provider;
    hidden var _onSaved as Method;
    hidden var _status as StatusView or Null = null;
    hidden var _onStatus = false;   // true while a StatusView (not a menu) is the flow's current screen
    hidden var _timer;
    hidden var _stops = [];
    hidden var _options = [];
    hidden var _stop = null;

    // onSaved: (index as Number) as Void
    function initialize(onSaved as Method) {
        _provider = ProviderRegistry.get(ProviderRegistry.DEFAULT_ID);
        _onSaved = onSaved;
        _timer = new Timer.Timer();
    }

    function start() as Void {
        _status = new StatusView(Fmt.str(Rez.Strings.FindingPosition));
        WatchUi.pushView(_status, new StatusDelegate(_status), WatchUi.SLIDE_LEFT);
        _onStatus = true;
        requestPosition();
    }

    function requestPosition() as Void {
        showStatus(Fmt.str(Rez.Strings.FindingPosition));
        _timer.start(method(:onPositionTimeout), GPS_TIMEOUT_MS, false);
        Position.enableLocationEvents(Position.LOCATION_ONE_SHOT, method(:onPosition));
    }

    function onPosition(info as Position.Info) as Void {
        _timer.stop();
        if (info.position == null) {
            onPositionTimeout();
            return;
        }
        var deg = info.position.toDegrees();
        showStatus(Fmt.str(Rez.Strings.Loading));
        Net.send(_provider.buildNearbyStopsRequest(deg[0], deg[1]), method(:onNearby));
    }

    function onPositionTimeout() as Void {
        Position.enableLocationEvents(Position.LOCATION_DISABLE, null);
        _status.setError(Fmt.str(Rez.Strings.NoPosition), method(:requestPosition));
    }

    function onNearby(code as Number, data) as Void {
        if (failed(code)) {
            return;
        }
        var stops = _provider.parseNearbyStops(data);
        if (stops == null) {
            _status.setError(Fmt.str(Rez.Strings.ParseError), method(:requestPosition));
            return;
        }
        if (stops.size() == 0) {
            _status.setError(Fmt.str(Rez.Strings.NoStopsNearby), method(:requestPosition));
            return;
        }
        _stops = stops;
        var menu = new WatchUi.Menu2({:title => Fmt.str(Rez.Strings.NearbyStops)});
        for (var i = 0; i < stops.size(); i++) {
            menu.addItem(new WatchUi.MenuItem(stops[i]["name"] as String,
                Lang.format(Fmt.str(Rez.Strings.DistanceFmt), [stops[i]["dist"]]), i, null));
        }
        WatchUi.switchToView(menu, new IndexMenuDelegate(method(:onStopChosen)), WatchUi.SLIDE_LEFT);
        _onStatus = false;
    }

    function onStopChosen(index as Number) as Void {
        _stop = _stops[index];
        showStatus(Fmt.str(Rez.Strings.Loading));
        Net.send(_provider.buildLineOptionsRequest(_stop["stopId"] as String), method(:onLineOptions));
    }

    function onLineOptions(code as Number, data) as Void {
        if (failed(code)) {
            return;
        }
        var options = _provider.parseLineOptions(data);
        if (options == null || options.size() == 0) {
            _status.setError(Fmt.str(options == null ? Rez.Strings.ParseError : Rez.Strings.NoLines),
                method(:requestPosition));
            return;
        }
        _options = options;
        var menu = new WatchUi.Menu2({:title => Fmt.str(Rez.Strings.ChooseLine)});
        for (var i = 0; i < options.size(); i++) {
            menu.addItem(new WatchUi.MenuItem(options[i]["label"] as String, null, i, null));
        }
        WatchUi.switchToView(menu, new IndexMenuDelegate(method(:onLineChosen)), WatchUi.SLIDE_LEFT);
        _onStatus = false;
    }

    function onLineChosen(index as Number) as Void {
        var o = _options[index];
        var fav = Model.favorite(_provider.id(), _stop["stopId"] as String, _stop["name"] as String,
            o["quayId"] as String, o["lineId"] as String, o["lineCode"] as String, o["label"] as String);
        var saved = FavoritesStore.add(fav);
        WatchUi.popView(WatchUi.SLIDE_RIGHT);
        _onSaved.invoke(saved);
    }

    // Shows a network error with retry; returns true if the request failed.
    hidden function failed(code as Number) as Boolean {
        var err = ServiceError.fromResponseCode(code);
        if (err == null) {
            return false;
        }
        _status.setError(ServiceError.message(err, code), method(:requestPosition));
        return true;
    }

    // Show text on the status screen, swapping it in if a menu is currently shown.
    hidden function showStatus(text as String) as Void {
        if (_onStatus) {
            _status.setText(text);
            return;
        }
        _status = new StatusView(text);
        WatchUi.switchToView(_status, new StatusDelegate(_status), WatchUi.SLIDE_IMMEDIATE);
        _onStatus = true;
    }
}
```
