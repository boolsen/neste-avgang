# Connect IQ Store listing: Neste avgang

## Name
Neste avgang

## Description (NO)
Se når bussen går – rett på klokka. Velg holdeplass og linje i riktig retning, og få sanntidsavganger i glance og app.

- Favoritter med nøyaktig plattform og retning – ingen avganger du ikke bryr deg om
- Legg til favoritter fra klokka: GPS finner holdeplasser i nærheten
- Tidsvindu: vis hjemme-holdeplassen om morgenen og sentrum om ettermiddagen
- Oversikt over alle favoritter, med sanntid og rullerende tekst
- Dekker all kollektivtrafikk i Norge via Entur (buss, trikk, tog, båt)

Krever tilkoblet telefon med internett. Posisjon brukes kun til å finne holdeplasser i nærheten og sendes ikke andre steder enn til Entur.

Data fra Entur, lisensiert under NLOD.

## Description (EN)
Real-time Norwegian public transport departures on your wrist. Save a stop + line + direction from the watch (GPS finds nearby stops), set time windows so the glance shows the right stop at the right time, and see all favorites at a glance. Covers all public transport in Norway via Entur. Requires a connected phone. App text is in Norwegian. Data from Entur (NLOD).
